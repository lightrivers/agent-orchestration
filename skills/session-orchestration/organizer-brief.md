# 整理员任务书（主会话派给 DeepSeek 子代理）

主会话派发前把 `<工作区>` 换成项目根目录的绝对路径，存成 `work/tasks/整理员.txt`，用 runner 后台运行（`--cwd <工作区>`）。

```
目标：整理项目文档，让新会话只读少量文件就能接手。

工作区：<工作区>。只改下面列出的文件，不改别的。

步骤：
1. 读 outputs/_收件箱.md 的所有条目，以及条目里提到的文件（只读需要的部分）。
2. 更新 outputs/状态.md：
   - 只改"当前状态""排队"（没有就新建）"会话分工"几节，使它们反映收件箱里的新情况。
   - 不改"规则""已定决策"两节。认为它们需要改，就写进报告的"建议"。
   - 全文控制在 10 KB 以内。被替代的旧内容原文移到 outputs/状态_会话记录.md 末尾（只追加，不删）。
   - 修改前先复制一份到 work/bak/状态_<时间>.md。
3. 更新 outputs/_索引.md：outputs/ 下每个文件或子目录一行：`路径 | 用途一句话 | 现行 / 已过时 / 被 X 替代`。不确定的标"待确认"。
4. 把已处理的收件箱条目移到 outputs/_收件箱_已处理.md 末尾，_收件箱.md 只留表头。

验收：状态文件 ≤10 KB；"规则""已定决策"两节和备份逐字相同；会话记录文件只增不减；索引覆盖 outputs/ 下所有条目。

交付：写 work/整理员/report_<时间>.md（改了哪些节、移走了多少内容、建议、待确认项），最后回复一行：结论 + 报告路径。
```
