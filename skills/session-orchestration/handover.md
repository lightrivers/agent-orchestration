# 主会话换届

## 旧主会话照做
1. 更新 `work/主会话_交接.md`（模板见文末），写明换届原因。"子会话"一栏列出每个子会话的名称、`local_…` id、在做什么、在等什么。
2. `start_session`（context `fresh`，`initiation` 按用户原话：用户要求的就用 "user_asked"），prompt："你是新的主会话。使用 session-orchestration skill，读 `work/主会话_交接.md` 后接任，然后向用户报告。"
3. 把 `work/当前主会话.md` 改成新会话的 id 和时间。
4. 对每个子会话和新主会话调用 `detach_session`。不 detach 的话，子会话每轮结束都会叫醒旧会话（冷缓存，很贵），归档旧会话时空闲子会话也会被一起归档。
5. `set_pinned`：新会话置顶，自己取消置顶。
6. 告诉用户"已换届，新主会话是 [标题](#local_id)"，然后 `archive_session("self")`。

正在执行 L2/L3 操作或长任务刚启动时，先到检查点再换。

## 新主会话
读 session-orchestration skill 和交接便签；按 SKILL.md"会话命名和分组"改自己的标题、归进项目分组；`list_sessions` 核对便签里的子会话；需要时读 `outputs/_索引.md`；向用户报告"已接任，在等的事有……"。

## 手动接任（旧主会话不照做时）
用户在 app 里新开会话说"接任主会话"。新会话：
1. 读 `work/当前主会话.md` 取旧 id，读 `work/主会话_交接.md`；交接便签过时的话，用 `list_events`（limit 20）看旧会话最近的记录补齐。
2. 把 `work/当前主会话.md` 改成自己的 id，`set_pinned` 置顶自己。
3. 告诉用户：子会话还挂在旧会话名下，只有旧会话能 detach。旧会话不要再对话，取消置顶；等它名下子会话都做完后由用户归档。

## 交接便签模板（≤2 KB）
```markdown
# <会话名> 交接 <日期时间>（原因：离开前 / 超阈值 / 变傻 / 用户要求）
- 目标：
- 已完成：（带证据路径）
- 正在跑：（进程/任务、怎么看进度、预计结束）
- 下一步：1–3 条
- 已定决策 / 不要做：
- 子会话：（名称、id、在做什么、在等什么）
- 等用户：（用户待办条目）
- 待审 / 杂项：
```
